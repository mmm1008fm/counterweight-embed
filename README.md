# Counterweight — Playable WebGL Embed

Compiled HTML5 / Unity WebGL embed build (v39) of **Counterweight** (Ludum Dare 60, Morning Tea Studio) for `<iframe>` embedding on landing pages.

- Live embed URL: `https://mmm1008fm.github.io/counterweight-embed/`
- Optional query params:
  - `?autostart=1` — start downloading immediately without click-to-play gate
  - `?lang=en` — English overlay labels (default: Russian)
  - `?nofs=1` — hide hover fullscreen corner button
